# FocusFlow

A wellness-first Pomodoro timer app built with Flutter. FocusFlow pairs focused work intervals with mood check-ins, ambient soundscapes, and a personal dashboard that helps users understand how they work best.

---

## Features

- **Pomodoro timer** — configurable focus duration, break duration, and sessions per sit
- **Break suggestions** — randomly selected wellness activities (movement, breathing, hydration, mindfulness) shown during each break
- **Ambient soundscapes** — 6 background tracks; selection persists across restarts
- **Session mood check-in** — log how you felt after each session (Great / Alright / Not so well / Bad)
- **Streaks & Badges** — calendar view of active days; automatic badge earning with local push notifications
- **Weekly Wellness Summary** — aggregated stats (hours, sessions, completion rate, avg mood) for the current week
- **Account management** — edit display name, export data as JSON, password reset, account deletion
- **Premium Paywall** — monthly / yearly plan selector (in-app purchase integration ready)

## Getting Started

### Prerequisites

- Flutter SDK `^3.10`
- A Firebase project with **Authentication** (Email/Password) and **Firestore** enabled
- Xcode (iOS) or Android Studio (Android)

### 1. Clone and install dependencies

```bash
git clone <repo-url>
cd FocusFlow
flutter pub get
```

### 2. Configure Firebase

If Firebase is not yet configured, run the FlutterFire CLI:

```bash
dart pub global activate flutterfire_cli
flutterfire configure --project=<your-firebase-project-id>
```

This generates `lib/firebase_options.dart` and the platform config files.

### 3. Firestore security rules

Set the following rules in the Firebase Console → Firestore → Rules:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      match /{subcollection}/{document} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
    }
  }
}
```

### 4. Run the app

```bash
flutter run
```

## In-App Purchases Setup

The paywall UI is fully implemented. To enable real purchases:

1. Register these product IDs in App Store Connect / Google Play Console:
   - `focusflow_premium_monthly`
   - `focusflow_premium_yearly`
2. Add StoreKit capability in Xcode (iOS)
3. The `PaywallCubit` will handle the full purchase flow automatically

## Adding Background Music

Drop `.mp3`, `.wav`, `.m4a`, `.ogg`, `.aac`, or `.flac` files into `assets/music/`. The app auto-discovers them on launch. To add a human-readable display name, add an entry to `_kDisplayNames` in `lib/services/music_service.dart`.
